My journey creating thumbnails started in 2017, however, I didn't start taking it more seriously until 2019. This is a thumbnail I created for a Minecraft tutorial I made for Valentine's Day. Since the beginning, I've always used Photoshop to add text or effects to my thumbnails, but this particular thumbnail marks a time when I started to use fonts that made sense, and more legible based on the sizing.
